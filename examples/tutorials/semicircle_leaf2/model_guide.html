Overview

This model implements the full four-equation auxin canalization system from Holloway et al. (2025) on a semicircular tissue with four concentric rings of cells. Auxin flows from a source ring (outer margin) to a sink ring (base), with canalization emerging from the positive feedback between auxin flux and plasmodesmata (PD) opening and PIN membrane allocation.

The model uses 14 reactions plus 2 compartment-change rules (division and removal). Three reaction classes were written specifically for this model; the rest reuse existing simulator classes.

File to edit: All parameters and the entire model string live in examples/tutorials/semicircle_leaf2/generate_tissue_files2.py. Run it to regenerate semicircle_leaf2.init, .model, and .solver before re-running the simulator.

Cell Types

Cell type is stored in cell variable index 1 and never changes at runtime. Types are assigned in generate_tissue_files2.py at the createSemicircle() function:

# line 97 -- r is the ring index (0 = base, nRings-1 = outer margin)
cellType = 1 if r == nRings - 1 else (2 if r == 0 else 0)
ValueIdentityRingWhat's different
0 Normal All middle rings Standard auxin production/decay only; Aprec starts at 0
1 Source Outermost ring (r = nRings-1) Creation::FromType ramps Aprec here; Aprec starts at 0.5. Acts as the margin source in the paper's model.
2 Sink Innermost ring (r = 0) Degradation::FromType adds extra auxin decay here (rate auxdec_sink). Mimics the paper's basal sink.
To add more cell types: add a new integer value (e.g., 3), assign it in the cellType logic above, then add a matching Creation::FromType or Degradation::FromType reaction in the model string with type_value = 3. Nothing in the C++ needs to change — the reactions are fully generic.

Equations & Reaction Mapping

The four coupled ODEs from the paper, and which simulator reactions implement each term:

Equation 1 — Auxin dynamics (cell variable A, index 3)
dAᵢ/dt = auxpr·Aprecᵢ − auxdec·Aᵢ [− auxdec_sink·Aᵢ if sink] + T · Σⱼ ( Pⱼᵢ·f(Aⱼ) − Pᵢⱼ·f(Aᵢ) ) ← PIN transport + D · Σⱼ Dᵢⱼ · (Aⱼ − Aᵢ) ← PD diffusion where f(x) = x / (1 + x)
Implemented by: reused Creation::One (auxpr·Aprec term)   reused Degradation::One (−auxdec)   reused Degradation::FromType (−auxdec_sink, sink only)   new PINSaturatingTransport (PIN term)   reused Diffusion::ConductiveSimple (PD term)
Equation 2 — Plasmodesmata dynamics (wall variable Dij, index 3)
dDᵢⱼ/dt = α · φᵢⱼ² + β − γ · Dᵢⱼ where φᵢⱼ = Dᵢⱼ·(Aⱼ − Aᵢ) is the local PD flux
Implemented by: reused Diffusion::ConductiveSimple (α·φ² − γ·Dᵢⱼ terms, using p₁=α, p₂=2, p₃=0, p₄=γ/α)   new Creation::OneWall (β background production on all walls)
Equation 3 — Cytoplasmic PIN pool (cell variable P, index 4)
dPᵢ/dt = pinpr·Aᵢ − pindec·Pᵢ − Σⱼ dPᵢⱼ/dt
The first two terms: reused Creation::One (pinpr·A)   reused Degradation::One (−pindec·P)   The −Σ dPᵢⱼ/dt conservation is automatic: MembraneCycling::UTGWTF adds to wallDerivs[Pᵢⱼ] and subtracts the same amount from cellDerivs[P], preserving total PIN.
Equation 4 — PIN membrane allocation (wall variables Pij / Pji, indices 1 / 2)
dPᵢⱼ/dt = kU · Pᵢ · g(Aⱼ) / (1 + Pᵢ) ← UTG term + Pᵢ / (1 + Pᵢ) · (kWq · φ² + kWl · φ) ← WTF term − koff · Pᵢⱼ ← dissociation where g(x) = K·x / (K + x), φ = saved PIN flux toward neighbor j
Implemented by: new MembraneCycling::UTGWTF (all three sub-terms combined). Reads the saved flux from wall indices 5/6 (written by PINSaturatingTransport).
Key insight — PD feedback: Diffusion::ConductiveSimple already implements both Eq. 1's PD-diffusion term and Eq. 2's Dᵢⱼ dynamics in one class. Setting its parameters p₂=2, p₃=0 matches the paper's additive α·φ² form exactly; no new C++ class was needed.

Parameters — Auxin (Eq. 1)

These control how auxin is produced, decays, and is transported. In generate_tissue_files2.py, look for the params dict around line 113.

aprec_ramp
Current: 0.01  |  Paper: 0.3–1.0
Rate at which the auxin precursor (Aprec) accumulates in source cells. Higher = faster buildup and earlier auxin gradient.
Increase to make the source “fire” faster. If too high the source auxin saturates before the tissue can canalize.
auxpr
Current: 0.05  |  Paper: ~0.5
Rate of auxin conversion from Aprec via Creation::One. Scales how efficiently the precursor drives auxin synthesis.
Raise to push more auxin into the tissue from the source. Keep ratio auxpr/auxdec > 1 to maintain a steady-state gradient.
auxdec
Current: 0.01  |  Paper: ~0.05
First-order auxin decay everywhere (Degradation::One). Sets the background decay floor.
Higher auxdec shortens the effective range of the auxin signal. If the gradient doesn't reach the sink, lower this first.
auxdec_sink
Current: 0.1
Extra auxin decay rate applied only to sink-type cells (type=2). Drives the auxin gradient toward the base by keeping auxin low there.
Must be significantly larger than auxdec to maintain a sink. Raise if auxin pools at the base instead of draining.
T_pin
Current: 1.0  |  Paper: ~6.0
PIN transport permeability — the T in Eq. 1. Scales how much PIN membrane concentration drives net auxin flow.
Increasing T strengthens PIN-mediated canalization. Very high T can cause oscillations if koff is too small. Paper uses T=6; try 2–4 as an intermediate step.

Parameters — Plasmodesmata (Eq. 2)

Control how the PD channels open (flux-feedback) and their background turnover. All implemented via Diffusion::ConductiveSimple plus Creation::OneWall.

D_pd
Current: 0.05  |  Paper: ~0.8
Baseline PD diffusion rate (p₀ in ConductiveSimple). Scales the Dᵢⱼ·(Aⱼ−Aᵢ) term in Eq. 1.
Higher D_pd makes PD diffusion the dominant transport mode (vs. PIN transport). For PIN canalization to dominate, keep D_pd smaller than T_pin.
alpha_pd
Current: 0.02  |  Paper: ~1×10²
PD opening rate driven by local auxin flux squared (α in Eq. 2). Higher = stronger positive feedback, faster canalization.
This is the Mitchison Type 1 canalization parameter. Increase to get narrow PD tracks; too high causes runaway Dᵢⱼ growth.
gamma_over_alpha
Current: 2.5  |  Paper: γ/α ≈ 500
Ratio γ/α, passed as p₄ to ConductiveSimple. γ is the PD closure/decay rate; γ/α sets the steady-state Dᵢⱼ ceiling.
Higher ratio → lower maximum Dᵢⱼ at steady state. Raise if Dᵢⱼ blows up; lower if PD tracks close too fast.
beta_pd
Current: 0.01  |  Paper: ~3×10−²
Constant background PD production rate on all walls (Creation::OneWall, β in Eq. 2). Prevents Dᵢⱼ from collapsing to zero off-track.
Small but nonzero value is important for stability. If PD completely disappears on non-track walls, increase beta_pd slightly.

Parameters — Cytoplasmic PIN Pool (Eq. 3)

pinpr
Current: 0.02
Rate of cytoplasmic PIN synthesis, proportional to local auxin (pinpr·A). Couples auxin levels to available PIN.
Higher pinpr → more PIN where auxin is high, amplifying asymmetric allocation. If Pᵢⱼ isn't building up near the source, increase this.
pindec
Current: 0.02
First-order cytoplasmic PIN decay. Together with pinpr sets the steady-state cytoplasmic pool P* ≈ pinpr·A/pindec.
Keep pindec ≤ pinpr so cells maintain a usable cytoplasmic PIN pool. If P collapses to near zero, lower pindec or raise pinpr.

Parameters — PIN Membrane Allocation (Eq. 4)

These govern the UTG (up-the-gradient) and WTF (with-the-flux) terms that direct PIN to specific wall faces, driving canalization. All in MembraneCycling::UTGWTF.

k_U
Current: 0.05  |  Paper: ~4×10−³
UTG term coefficient — allocates PIN to walls facing higher-auxin neighbors. The classic Mitchison Type 2 (up-the-gradient) mechanism.
Increase to strengthen up-gradient allocation. If PIN symmetry doesn't break, raise k_U first.
k_off
Current: 0.02
PIN dissociation rate from the membrane back to cytoplasm. Controls how quickly asymmetric allocation can re-equilibrate.
If PIN “freezes” in one direction too early, increase k_off to allow redistribution. Very low k_off can cause early locking before canalization.
K_utg
Current: 2.0  |  Paper: 100
Half-saturation constant in the UTG auxin-sensing function g(x) = K·x/(K+x). Scales the auxin sensitivity of the UTG mechanism.
Set relative to typical auxin levels. Paper uses K=100 (auxin in the tens range); our tissue has auxin ~0.5–3, so K=2 is appropriate. Increase K if UTG saturates immediately.
k_Wq
Current: 0.5  |  Paper: ~1×10−&sup5;
WTF quadratic term coefficient — allocates PIN to walls carrying higher PIN-flux squared. The self-reinforcing canalization mechanism.
This is the strongest canalization driver. Increase carefully — too high causes runaway PIN concentration. Start with k_Wl changes first.
k_Wl
Current: 0.1  |  Paper: ~3×10−³
WTF linear term coefficient — like k_Wq but linear in flux. Contributes to canalization with less potential for blow-up than the quadratic term.
Safer than k_Wq to increase. If you want stronger WTF, raise k_Wl before k_Wq.
Note on paper vs. simulator scales: The paper's parameters (T=6, kU=4×10−³, etc.) are calibrated to a full leaf geometry with auxin concentrations in the tens range. Our 4-ring semicircle with R_max=10 reaches auxin ~0.5–3. All parameters need to be re-scaled proportionally — the ratios between them matter more than absolute values.

Parameters — Growth & Division

k_growth_radial
Current: 0.006
Rate of vertex displacement outward from the center (MoveVertexRadially). Growth is exponential: fast-growing tissue divides often, slow tissue barely changes shape.
Raise for more rapid tissue expansion. At t=100 with current value, the tissue roughly doubles in area.
k_growth_wall
Current: 0.048
Wall stress-driven growth rate (WallGrowth::Stress). Walls stretched beyond rest length grow to relieve strain.
Increase for faster wall elongation. If cells become highly elongated without dividing, lower V_threshold or raise this.
K_spring
Current: 0.01
Wall spring stiffness (VertexFromWallSpring). Balances vertex positions along walls. Low value = soft tissue.
Increase if cell shapes become irregular or vertices drift unrealistically. Too high causes stiff oscillations.
V_threshold
Current: 8.0
Cell volume at which Division::ShortestPath2D triggers. Initial cell volume is 0.9; must grow ~9× before dividing.
Lower = more frequent division, more cells, slower simulation. Raise to reduce division events if the tissue grows too complex.
R_removal
Current: 500.0
Cells whose center exceeds this radius are removed (RemovalOutsideRadius). Set large enough not to clip the tissue.
Only relevant if the tissue grows very large. With R_max=10 and t=100, the outer radius stays well below 500.

Building & Running

Rebuild after any C++ change
# in WSL, from the tissue-simulator root
cd src
make -j4
Regenerate model files & run
# from the semicircle_leaf2 directory
python3 generate_tissue_files2.py          # writes .init, .model, .solver
../../../bin/simulator semicircle_leaf2.model semicircle_leaf2.init semicircle_leaf2.solver
Save output before re-running
# copy the vtk folder to a named results snapshot
cp -r vtk results/my_experiment_name/
# save the generator too so you can reproduce it
cp generate_tissue_files2.py results/my_experiment_name/
Solver settings — semicircle_leaf2.solver
RK5Adaptive
0 100         # start time, end time
2 100         # output every 2 t-units, 100 total frames
0.5 1e-5      # initial stepsize, tolerance

To run longer, change 0 100 to 0 500 and adjust the output interval. To get more frames, lower the interval (e.g., 1 500 for 500 frames). Edit the solver string in generate_tissue_files2.py.

If the solver crashes with stepsize underflow: the RK5Adaptive solver has tiny = 1e-6 (fixed in src/rungeKutta.cc line ~32) to prevent chasing floating-point noise on freshly created wall variables after division. If you still see underflow, try lowering T_pin or k_Wq first before touching solver tolerances.

Tuning Tips

Signs that canalization is working
  • Auxin shows a gradient from outer ring → base, not a uniform plateau.
  • Pij and Pji are asymmetric on walls along the source-to-sink axis.
  • Dij is higher on walls that carry sustained flux and lower off-track.
  • The auxin “stripe” narrows over time rather than broadening.
Common failure modes
SymptomLikely causeTry
Auxin high everywhere, no gradient auxdec too small, auxdec_sink not large enough Raise auxdec_sink to 0.3–0.5; lower auxpr slightly
Auxin never builds up auxdec or auxdec_sink too large Raise auxpr; check aprec_ramp is nonzero
PIN stays symmetric (no canalization) k_U and k_Wl too small to break symmetry Raise k_U to 0.1–0.2; try k_Wl = 0.5
Solver underflow crash T_pin or k_Wq too large, creating rapid flux spikes Halve T_pin or k_Wq; verify tiny=1e-6 in rungeKutta.cc
Dij collapses to zero everywhere gamma_over_alpha too large or beta_pd too small Lower gamma_over_alpha to 1.0; raise beta_pd to 0.05
Division explosions / many tiny cells V_threshold too low relative to growth rate Raise V_threshold to 12–16; lower k_growth_radial
Scaling parameters toward paper values

The paper (larger leaf geometry, auxin in the tens) uses significantly different absolute values. Scale incrementally — change one parameter at a time, run to t=50, then check the auxin range in ParaView before proceeding.

Recommendation: Save a copy of the vtk/ output and the generator script to a named results/ subfolder before each experiment so you can always roll back to a working state. Use the params dict at the top of generate_tissue_files2.py — it centralizes every tunable value in one place.

createSemicircle(
    nRings=4,    # radial cell layers (depth from sink to source)
    nCols=14,   # columns around the arc (width of tissue)
    ...
)

More rings = more cell layers between source and sink, longer canalization path. More columns = wider tissue, more cells per ring. Total cell count = nRings × nCols.

Initial variable values — lines 73–78
