# semicircle_leaf2.model — annotated reference
#
# This file mirrors semicircle_leaf2.model line-for-line, with comments explaining
# every number. The actual .model file cannot contain comments (the parser would fail),
# so keep this file in sync manually when parameters change.
#
# Format rules:
#   Line 1 of each block: reaction/compartment-change name
#   Line 2: numParams  [count_at_level_0  count_at_level_1 ...]
#               "levels" are groups of variable indices; level 0 is usually cell vars,
#               level 1 is usually wall vars.  Some reactions use more levels.
#   Remaining lines: parameter values first (one per line), then index values.
#
# Variable index reference (as initialized in generate_tissue_files2.py):
#
#   CELL variables (5 total):
#     cell[0]  volume tracker   — grows with cell; triggers division when > V_threshold
#     cell[1]  type             — 0=normal interior, 1=source (outer ring), 2=sink (base ring)
#     cell[2]  Aprec            — auxin precursor; ramped up in source cells only
#     cell[3]  A                — auxin concentration  (Eq. 1 in Holloway et al. 2025)
#     cell[4]  P                — cytoplasmic PIN pool (Eq. 3)
#
#   WALL variables (6 total, indexed 0–5 in wall.variable()):
#     wall[0]  Pij              — PIN on the i-side of the wall (i→j direction)  (Eq. 4)
#     wall[1]  Pji              — PIN on the j-side of the wall (j→i direction)  (Eq. 4)
#     wall[2]  Dij              — plasmodesmata (PD) cross-sectional area         (Eq. 2)
#     wall[3]  Dij_mirror       — symmetric copy of Dij (required by DiffusionConductiveSimple)
#     wall[4]  flux_ij          — saved PIN-transport flux i→j (read by UTGWTF WTF term)
#     wall[5]  flux_ji          — saved PIN-transport flux j→i
#   (wall length is a built-in separate field, NOT counted in the indices above)
#
# ─────────────────────────────────────────────────────────────────────────────

14    # total number of reactions
2     # total number of compartment changes (cell division / removal)
0     # number of direction (polarity) models — none used here

# ── Reaction 10 ─────────────────────────────────────────────────────────
Diffusion::ConductiveSimple
# Source: src/transport.h, src/transport.cc  (class DiffusionConductiveSimple)
# Effect: implements BOTH the PD-diffusion term of Eq. 1 AND the PD-area dynamics of Eq. 2:
#
#   Eq. 1 contribution:  dA_i/dt += D_pd · Σ_j Dij · (Aj − Ai)
#   Eq. 2:               dDij/dt  = alpha_pd · flux² − gamma · Dij
#
#         The same wall variable (Dij) serves as both the diffusion conductance and
#         the dynamic state.  Flux-squared feedback makes walls carrying more auxin
#         traffic open wider over time (positive feedback → canalization of PD).
5 2 1 2     # 5 parameters; level-0 has 1 cell-var index; level-1 has 2 wall-var indices (Dij + mirror)
0.15        # D_pd              — baseline PD diffusion coefficient  (paper: 0.8)
0.02        # alpha_pd          — flux² feedback strength: rate at which flux widens PD pores
2           # p2                — power of flux in the feedback term (2 = flux-squared)
0           # p3                — power of a second flux term (0 = disabled)
5.0         # gamma_over_alpha  — ratio γ/α; sets the steady-state Dij ceiling at high flux
3           # level-0[0]        — auxin variable: cell[3] = A
3           # level-1[0]        — Dij wall variable index: wall[3] (primary, dynamics here)
4           # level-1[1]        — Dij_mirror wall variable index: wall[4] (kept equal to Dij since PD pores
            #                     are physically symmetric; same derivative written to both slots)

# ── Reaction 14 ─────────────────────────────────────────────────────────
MembraneCycling::UTGWTF
# Source: src/membraneCycling.h, src/membraneCycling.cc  (class MembraneCycling::UTGWTF) — ADDED THIS PROJECT
# Effect: allocates cytoplasmic PIN to each wall face according to two mechanisms:
#
#   UTG ("Up The Gradient"): biases PIN toward whichever neighbour has more auxin.
#         f(Aj) = 100·Aj / (100 + Aj)  saturates at high auxin.
#         Initiates canalization by detecting the auxin gradient.
#
#   WTF ("With The Flux"): reinforces PIN on walls that already carry net flux.
#         Reads flux_ij saved by PINSaturatingTransport (Reaction 9).
#         Narrows channels once established — does not initiate flow alone.
#
#   k_off term recycles Pij back to cytoplasm, balancing deployment.
#   Conservation enforced: wallDerivs[Pij] += fac,  cellDerivs[P] -= fac.
5 3 2 1 1   # 5 parameters; level-0 has 3 indices; level-1 has 2; level-2 has 1; level-3 has 1
0.1         # k_U          — UTG allocation rate constant
0.05        # k_off        — PIN recycling rate (membrane → cytoplasm)
2.0         # K_utg        — half-saturation constant for cytoplasmic PIN in UTG term
0.15        # k_Wq         — WTF quadratic flux coefficient (flux² term; sharper canalization)
0.2         # k_Wl         — WTF linear flux coefficient  (flux¹ term; broader initial response)
3           # level-0[0]   — auxin variable: cell[3] = A  (read by UTG for neighbour comparison)
4           # level-0[1]   — cytoplasmic PIN variable: cell[4] = P
1           # level-0[2]   — Pij wall variable index: wall[1] (PIN on i-side, updated here)
5           # level-1[0]   — flux save start index: wall[4] = flux_ij (read for WTF term)
            #                 wall[5] = flux_ji is implicitly flux_save_index + 1
